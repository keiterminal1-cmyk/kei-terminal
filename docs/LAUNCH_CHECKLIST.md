# Kaspa Radar Launch Checklist

## Before public launch
- Replace placeholder project data with verified sources.
- Add real API IDs for every tracked asset.
- Add a real domain in `sitemap.xml`.
- Add legal pages for your jurisdiction.
- Add analytics only after privacy review.
- Protect any real admin backend with authentication.
- Keep financial disclaimer visible.

## Recommended first public version
- Free dashboard
- Manual watchlist
- Mining calculator
- KAS live data
- Demo data for smaller ecosystem projects clearly marked

# KEI Score Model

KEI = Kaspa Ecosystem Intelligence Score.

## Formula
- Development: 30%
- Adoption: 25%
- Liquidity: 20%
- Community: 15%
- Fundamentals: 10%

## Opportunity Score
Opportunity = KEI * 45% + Momentum * 35% + Safety * 20%

Safety = 100 - Risk Score

## Production data sources
- Market data: CoinGecko, CoinMarketCap, exchange APIs
- TVL: DefiLlama or protocol APIs
- Development: GitHub APIs
- Community: X, Telegram, Discord, website traffic
- Adoption: wallet growth, transactions, active users
